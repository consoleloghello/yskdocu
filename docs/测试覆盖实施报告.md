### 修复的测试问题

在编写测试过程中发现并修复了 4 个测试用例问题（不是代码 bug，是测试预期不准确）：

1. **`test_no_style`** — `is_chapter_heading()` 在 style 为 None 时返回 `None` 而非 `False`
2. **`test_with_closing_paren`** — `split_inline_options()` 不分割 `A)` 格式的选项（已知限制）
3. **`test_long_text`** — `looks_like_new_question()` 需要文本以标点结尾才返回 `True`
4. **`test_consecutive_formatted_runs`** — 连续 bold run 的收集在非 bold run 处停止，预期行为
