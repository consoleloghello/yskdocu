# 公用工程题库 SPA — 方案设计（现状 as-built）

> 更新：2026-07（重构后）。本文描述当前代码的实际结构，替代早期落地前的设计稿。

## 一、概述

化工企业公用工程岗位的移动端刷题 SPA。将 docx 题库解析为结构化 JSON，前端以纯静态方式部署在 GitHub Pages。支持外操版/内操版两套题库、9 大专业系统；登录用户通过 Supabase 获得错题、笔记、答题统计、纠错反馈的云同步。

## 二、技术栈

| 类别 | 选择 |
|---|---|
| 文档解析 | Python 3 + python-docx |
| 前端 | Vanilla JS（IIFE 模块化，零构建）+ CSS3 |
| 数据 | 静态 JSON + gzip（.json.gz）+ localStorage + Supabase（PostgreSQL） |
| 图表 | Chart.js v4（CDN） |
| 背景动画 | p5.js（CDN；reduced-motion / 移动端默认关闭） |
| 测试 | pytest（解析器）+ JSDOM 冒烟测试（smoke_test.mjs） |
| 部署 | GitHub Pages（GitHub Actions：测试 → 解析 → 压缩 → 发布） |

## 三、架构

### 数据管道

```
.docx 源文件 → scripts/parse_docx.py → data/外操版.json + data/内操版.json
        → npm run compress → data/*.json.gz
        → 浏览器 fetch()（优先 .gz，失败降级 .json）→ 渲染题目卡片
```

### 前端模块（按加载顺序）

| 文件 | window 全局 | 职责 |
|---|---|---|
| `state.js` | `State` | 状态存储（pub/sub）、localStorage 持久化、转义/高亮/防抖工具 |
| `filter.js` | `Filter` | 题目筛选纯函数：searchIn / countByType / getCurrentQuestions |
| `decompress.js` | `Decompress` | 浏览器端 gzip 解压（DecompressionStream），自动降级 .json |
| `renderer.js` | `Render` | DOM 渲染、统计图表 |
| `data.js` | `Data` | loadData / buildFlat（稳定 _id + 迁移）/ pullCloudData |
| `app.js` | — | 入口：事件委托、弹窗、版本切换、订阅渲染 |
| `supabase.js` | `SupabaseAuth` | 认证：邮箱密码注册/登录、OTP 验证、登出 |
| `sync.js` | `Sync` | 云端 CRUD：错题、笔记、统计 RPC、报错 |
| `background-motion.js` | `BgMotion` | 背景动画开关/暂停守卫 |
| `background-synthetic-flux.js` / `background-quantum-foam.js` | — | p5.js 背景动画（入口遮罩 / 主页面） |

### 状态管理

`State` 采用极简 pub/sub：`set()` / `setMulti()` 自动持久化并通知订阅者（`app.js` 订阅 `render`）。原先散落的「改状态 + saveState + render」已收敛为单一数据流。

## 四、数据模型

### JSON 结构（data/*.json）

```json
{
  "info": { "title": "公用工程题库（外操版）", "version": "外操版", "total": 357 },
  "chapters": [
    {
      "name": "火炬",
      "type_groups": [
        { "type": "选择题", "questions": [ { "question": "...", "options": ["A. ..."], "answer": "B" } ] }
      ]
    }
  ]
}
```

### 展平模型（flatQs，运行时由 buildFlat 生成）

```javascript
{
  _id: "火炬_选择题_0",   // 稳定 ID：章节_题型_本题型内序号
  _chapter: "火炬",
  _type: "选择题",
  question: "...",
  options: ["A. ..."],     // 仅选择题
  answer: "B" | "√" | "×" | text
}
```

### 题目 ID 与迁移

- `_id` = `章节_题型_本题型内序号`，插入新题只影响本题型，跨题型不串位（旧版全局自增会全量漂移）。
- `buildFlat()` 同时生成 `State.legacyIdMap`（旧 ID → 新 ID），本地错题本、云端错题/笔记在加载时自动迁移。

### localStorage

| Key | 内容 |
|---|---|
| `ysk_state` | `{ version, chapter, type, searchQuery, mode, wrongBook, stats }` |
| `ysk_revealed` | 已显示答案的题目 ID 数组 |
| `ysk_wrong_外操版` / `ysk_wrong_内操版` | 各版本错题本 `{ id: true }` |
| `ysk_changelog_seen` | 最近看到的 commit hash |

## 五、docx 解析器（scripts/parse_docx.py）

- **章节检测**：`Heading 2` 样式 + 居中对齐，自动发现新章节。
- **题型检测**：`一、` ~ `十、` 前缀 + 括号后缀处理（如 `三、判断题（含答案…）`）。
- **选项收集**：统一处理内联（`A. xxx B. xxx`）与逐行两种格式。
- **答案提取**：选择题 `（A）`、判断题 `（√/×）`；填空题从加粗/下划线 run 提取并替换为 `____`。
- **简答/实操/应急**：启发式 `looks_like_new_question()` 合并多段答案。

## 六、关键约束

- 零构建；移动端优先（适配 320px）。
- 中文文件名：JSON 用中文名，`serve.mjs` 做 `decodeURIComponent` 处理。
- localStorage 是匿名用户唯一持久化；登录用户以 Supabase 为主存储、localStorage 为缓存。
- CDN：supabase-js、Chart.js、p5.js（离线时匿名刷题不受影响）。
